# 04 接触势垒与动态刚度

项目接触处理的核心是**势垒函数（barrier）** + **弹性包含的动态刚度（elasticity-inclusive dynamic stiffness）**。目标是实现**穿透-free**（无穿透）的鲁棒接触，同时在轻接触时避免过度刚化导致的 artifacts。

**主论文标题**即点明创新：“A Cubic Barrier with Elasticity-Inclusive Dynamic Stiffness”（ACM TOG 2024）。本篇严格基于项目源码中的三种势垒实现 + compute_stiffness + hindsight 勘误。

## 三种势垒的精确公式

统一调度（`barrier/barrier.cu:13`）：
```cpp
if (Cubic) return cubic::...;
else if (Quad) ...
else if (Log) ...
```

### 1. Cubic（项目默认/特色，`barrier/cubic.hpp:13-40`）

```cpp
g -= offset; y = g - ghat;
energy = (y < 0) ? -2.0f * (y*y*y) / (3.0f * ghat) : 0;
grad   = (y < 0) ? -2.0f * y*y / ghat : 0;
curv   = (g - ghat < 0) ? 4.0f * (1.0f - g / ghat) : 0;
```

**特性**：
- 仅在 g < ghat 时激活。
- 曲率在 g = ghat 处为 0，在 g = 0 处达到 4κ（线性增长）。
- 这使得系统在“刚刚接触”时不会突然僵硬，而是逐渐 stiffen。

**与 hindsight 相关**：见下文 quadratic 修正讨论。

### 2. Quadratic（简单常数曲率，`barrier/quadratic.hpp:13-40`）

```cpp
g -= offset; y = ghat - g;
energy = (y > 0) ? y*y : 0;
grad   = (y > 0) ? -2*y : 0;
curv   = (ghat - g > 0) ? 2 : 0;
```

**Hindsight 勘误（`articles/hindsight.md`）**：
论文最初给出的 quadratic 对应是 `κ/(2 ghat) (g-ghat)^2`，其曲率是常数 κ/ghat，与“弹性包含刚度应 ~ κ”的假设不符。
**推荐修正为**：
```math
\psi^{\mathrm{new}}_{\mathrm{quad}} = \kappa (g - \hat g)^2
```
（曲率恒为 2κ？按代码当前实现曲率为常数 2，参数 κ 通过上层 stiff_k 乘入。）

**问题**：quadratic 在 g < ghat 区域曲率立即达到最大，导致轻接触时系统不必要地僵硬，易产生 snag artifacts（多米诺骨牌轻推场景尤为明显）。Cubic 则从 0 逐渐上升到 4κ，更“智能”。

### 3. Log（平滑对数，`barrier/logarithm.hpp:13-40`）

```cpp
g -= offset;
if (g <= 0) return ±∞（能量/梯度/曲率）;
if (g >= ghat) return 0;
energy = -(g-ghat)*(g-ghat) * log(g / ghat);
grad   = (ghat-g) * (2*g*log(g/ghat) + g - ghat) / g ;
curv   = -2*log(g/ghat) + ghat*(ghat + 2*g)/(g*g) - 3;
```

经典 IPC 家族 smoothed log 势垒，C^∞ 在 (0, ghat) 内，g→0+ 发散更强。

## compute_stiffness：弹性 + 动态质量的混合

**声明与特化**（`barrier/barrier.hpp:21` + `barrier.cu:49`）：

```cpp
template <unsigned N>
__device__ float compute_stiffness(const Proximity<N> &prox,
    const SVecf<N> &mass, const FixedCSRMat &hess,
    const Vec3f &e, float ghat, float offset, const ParamSet &param);
```

**核心逻辑**（N=2/3/4，VF/EE/PE/VV 等）：
1. g = ||e|| - offset；sqr_x = g*g
2. **静态侧质量替换**（关键数值洞见，59-63 行注释）：
   - 若 mass[ii]==0（固定/kinematic/碰撞体），用组内 m_max 代替。
   - 否则接触刚度只感受到“单侧惯性”，在强碰撞时不稳定。
3. 构建 local_hess（N*3 × N*3）：
   - 拉取当前**弹性 hessian 子块** hess(prox.index[ii], jj)
   - 对角块额外 + (m_ii / sqr_x) * I
4. 构造带 bary 权重的方向 w（prox.value * e 归一化）
5. 返回 w^T * local_hess * w（即沿接触分离方向的有效刚度）

**上层使用**（`contact/contact.cu:213` 示例）：
```cpp
float stiff_k = barrier::compute_stiffness<N>(prox, mass, fixed_in, ex_fp, ...);
...
f = stiff_k * barrier::compute_edge_gradient(ex_fp, ghat, offset, barrier);
H = stiff_k * barrier::compute_edge_hessian(...);
if (include_friction) { Friction ...; f += _friction.gradient(); H += ...; }
extend_contact_force_hess<N>(prox, f, H, ...);  // 按 bary 分布到多个顶点
```

辅助函数：
- `compute_edge_gradient(e, ...)` = n * gradient(||e||, ...)
- `compute_edge_hessian` = curv * (e e^T / ||e||²)（rank-1）

## 应变限制对势垒的复用

`barrier::compute_strainlimiting_diff_table`（116 行）：
- 把 stretch a[i] 视作“g”
- y = ghat - g（注意符号翻转，over-stretch 对应“穿透”）
- deda[i] = -gradient(y, ghat, 0, barrier)
- d2 直接 = curvature（对角）
- 随后仍走 eigenanalysis 路径（壳）或解析 PSD（杆）。

`strainlimiting_energy` 类似累加。

这实现了“统一势垒语言”：接触用 gap，strainlimit 用 (stretch-1)。

## Push 单侧约束（碰撞网格/球/地板常用）

`energy/model/push.hpp` 提供类似 cubic 的单侧投影势（已知 normal 方向）：
```cpp
d = e.dot(normal);
energy = (d<0) ? -cube(d)/(3*eps) : 0;
grad   = (d<0) ? -sqr(d)/eps * normal : 0;
curv   = (d<0) ? -2*d/eps : 0;
hess   = curv * n n^T;
```
常与简化 stiffness（normal 方向投影 + mass/gap²）一起用于静态碰撞体。

## 势垒参数与选择

- `ParamSet.barrier`（Cubic/Quad/Log）
- `ghat`：每对象/每组可独立（FaceParam / TetParam / ... + 全局）
- `offset`：厚度/安全裕度（自接触或碰撞体厚度累加）
- 上层 `stiff_k` 实际控制“κ”（论文中 κ 与材料刚度相关）
