# 05 摩擦模型与应变限制

本篇介绍两个紧密相关的“约束力”机制：**正则化 Coulomb 摩擦**（叠加在接触势垒力之上）与 **应变限制（strain limiting）**（复用势垒思想，强约束三角形/杆边不能过度拉伸）。

两者都产生力与 Hessian 贡献，都参与独立的线搜索 TOI 计算，最终都服务于“无穿透 + 无过度应变”的物理真实性。

## 摩擦模型（Friction 结构体）

位置：`energy/model/friction.hpp:12`

```cpp
struct Friction {
    const Vec3f &dx;
    Mat3x3f P;
    float lambda;
    float mu;
    float contact;

    __device__ Friction(const Vec3f &force_contact, const Vec3f &dx,
                        const Vec3f &normal, float mu, float min_dx)
        : dx(dx), mu(mu) {
        contact = -normal.dot(force_contact);   // 法向压紧量（>0 表示压缩）
        P = get_projection(normal);             // I - n n^T 切向投影

        if (mu > 0.0f) {
            float denom = (P * dx).squaredNorm();
            lambda = mu * contact / fmax(min_dx, sqrt(denom));
            // 若切向速度极小，用 min_dx 保护
        } else lambda = 0;
    }

    __device__ Vec3f gradient() const { return lambda * (P * dx); }
    __device__ Mat3x3f hessian() const { return lambda * P; }
};
```

**物理近似**：
- 经典 Coulomb：f_t ≤ μ |f_n|
- 这里实现的是**正则化速度版本**：f_t ≈ μ |f_n| * (v_t / max(ε, |v_t|))
- dx 通常取相对运动（当前步内或与前一帧），P 投影到切平面。
- Hessian 是 λ P（各向同性切向阻尼的线性化）。

**平滑参数**：`param.friction_eps`（min_dx），防止除零与过刚切向。

**combine 模式**（`contact/contact.cu:35`）：
```cpp
float combine_friction(float a, float b, FrictionMode mode)
```
支持 Min / Max / Mean，用于跨 vertex/edge/face param 取摩擦系数（避免不一致）。

**添加位置**：
- 在 barrier / push 产生的接触力 f 与 H 之后立即：
  ```cpp
  Friction _friction(f, dx, normal, friction, param.friction_eps);
  f += _friction.gradient();
  H += _friction.hessian();
  ```
- 然后 extend_by_bary + atomic embed。
- 同样用于 sphere/floor/collision-mesh 约束（`embed_vertex_constraint...`）。

**与接触势垒的关系**：摩擦只在**有法向压紧**（contact >0）时激活，方向与 barrier 力正交（切向）。

## 应变限制（Strain Limiting）

目标：对壳面与杆边施加**硬上限** `strainlimit`（例如 5%），防止三角形/杆过度拉伸（即使在高应力场景下也严格遵守）。

**实现哲学**：把“过度 stretch”视作“势垒穿透”，**复用同一 barrier 机制**。

### 壳面（3×2 F 路径）

1. 计算当前 F（或 F0/F1 用于 LS）
2. `svd = svd3x2_shifted(F)` 得到 S（实际代码常用 singular_vals_minus_one 即 σ-1）
3. `limit = (strainlimit + 1)/shrink_min - 1`（考虑各向异性 shrink）
4. `DiffTable2 table = barrier::compute_strainlimiting_diff_table(svd.S, fparam.strainlimit, barrier)`
   - 内部 y = ghat - g，g = S[i]；deda/curv 符号翻转后得到“拉伸方向”的 barrier 贡献
5. **stiffness 估计**（`compute_stiffness` in strainlimiting.cu:22）：
   - 类似接触版：用当前 eval_x 构造局部 9×9 弹性 hess 块 + mass / d²（d = limit - max_S）
   - 方向 w 来自面局部坐标（质心到三顶点）
6. `dedF = eigenanalysis::compute_force(table, svd)`
7. `d2edF2 = eigenanalysis::compute_hessian(table, svd, param.eiganalysis_eps)`
8. convert + stiffness * atomic_embed

**关键**：应变限制的 Hessian 写到 **fixed_hess**（与弹性共享），但 stiffness 是**额外**的（动态估计的“约束刚度”）。

### 杆（直接边长路径）

- g = l / l0 - 1
- 直接用 barrier gradient/curvature（无 eigen）
- Hessian 采用**解析 PSD 形式**（`a * (J J^T) + b * Hg`，a/b = max(0,·) 夹取）
- stiffness = `compute_rod_stiffness`（局部 hess 投影 + mass / (limit-g)²）
- 见 `strainlimiting.cu:94` 起 `embed_rod_strainlimiting...`

### 线搜索（独立于接触 CCD）

应变限制有**自己精确的二分线搜索**，保证在接受步长内 stretch ≤ limit。

**壳面**（`strainlimiting.cu:236` 及后续）：
- F0（prev）、F1（目标）、dF
- 二分 t 使 `singular_vals_minus_one(F0 + t*dF).max < limit`
- 窗口不变即退出（防 FP 死循环）
- 返回归一化 TOI

**杆**（`rod_line_search:181`）：
- 类似二分 ` (d0 + t*dd).norm()/l0 -1 >= limit `
- 最终全局 `min( contact_toi, strain_toi, rod_toi )`

**在 Newton 中的位置**（`main/main.cu`）：
- 弹性之后、接触之前装配 strainlim force/hess
- line_search 在接触 CCD 之后取 min（若 strain 更紧则提前停止）

### 与 barrier / eigen 的关系

- 壳应变限制：**完全复用** barrier（作为 stretch 的势垒）+ eigenanalysis（产生 PSD 雅可比）+ convert。
- 杆应变限制：复用 barrier 公式，但**解析**构造 PSD hess（无需 2×2 eigen）。
- 这使得“接触”与“应变上限”在数学语言上统一，代码复用度高。

### 参数

- `FaceParam.strainlimit` / `EdgeParam.strainlimit`（per-object 可设）
- `shrink_x/y`：各向异性上限缩放
- 全局 `line_search_max_t`
