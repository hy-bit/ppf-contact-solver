# 01 有限元离散化与变形梯度

本篇介绍项目中实际采用的有限元离散化方式：支持**壳（三角形面）**、**体（四面体）** 与 **杆（边 + 弯曲）** 的混合维度模拟。核心概念是**变形梯度 F**（对壳为 3×2，对体为 3×3）及其从当前顶点位置到 rest 参考形状的映射。

**范围控制**：仅描述项目实现中用到的内容，不展开通用 FEM 教科书知识。杆件不使用 F，而是直接使用边长与角度。

## 元素类型与拓扑

- **壳（Shell / Face）**：
  - 三角形面（face）：每个面 3 个顶点。
  - 弯曲通过 **hinge**（四顶点铰链，对应两个相邻三角形共享边）。
  - 变形梯度：3×2 矩阵 F（列空间为两个切向基）。
  - 典型模型：ARAP / StVK / SNHk / BaraffWitkin（拉伸+剪切）+ 二面角弯曲能。

- **体（Solid / Tet）**：
  - 四面体（tet）：每个单元 4 个顶点。
  - 变形梯度：3×3 矩阵 F。
  - 典型模型：ARAP / StVK / SNHk + detsqr 体积。

- **杆（Rod / Edge + Bend）**：
  - 边（edge）：2 顶点，用于拉伸（Hook 能）。
  - 弯曲：仅当一个顶点恰好连接 2 条杆边且不属于任何面时触发，使用三点 strand 角度（`dihedral_angle::strand_*`）。
  - **不使用 F**，直接操作当前长度 l 与参考长度 l0、角度 theta 与 rest_angle。

数据结构关键字段（`data.hpp`）：
- `shell_face_count`、`tet_count`、`rod_count`、`hinge_count`
- `Mesh`（faces/edges/vertices） + `Prop`（每元素质量、面积/长度、固定标记、param_index）
- `inv_rest2x2`（壳，数量 = face 数）、`inv_rest3x3`（体，数量 = tet 数）
- `VertexProp.rest_angle` / `rest_bend_angle`（弯曲参考角度）
- `EdgeProp.initial_length`

## 变形梯度 F 的定义与计算

对线性单元，F 描述当前构型相对于 rest 参考的线性映射。项目中 F **不是** 直接从世界坐标差分得到，而是：

```
F = dx_current * inv_rest
```

其中 `dx_current` 是当前顶点位置在局部基下的边向量矩阵，`inv_rest` 是 rest 形状下相同边向量矩阵的逆（预计算）。

**精确实现**（`utility/utility.cu:205`）：

```cpp
// File: utility/utility.cu
__device__ Mat3x2f compute_deformation_grad(const Mat3x3f &x,
                                            const Mat2x2f &inv_rest2x2) {
    Mat3x2f dx;
    dx.col(0) = x.col(1) - x.col(0);
    dx.col(1) = x.col(2) - x.col(0);
    return dx * inv_rest2x2;
}

__device__ Mat3x3f compute_deformation_grad(const Mat3x4f &x,
                                            const Mat3x3f &inv_rest3x3) {
    Mat3x3f dx;
    dx.col(0) = x.col(1) - x.col(0);
    dx.col(1) = x.col(2) - x.col(0);
    dx.col(2) = x.col(3) - x.col(0);
    return dx * inv_rest3x3;
}
```

**调用示例**（应变限制，壳）（`strainlimiting/strainlimiting.cu:66`）：

```cpp
Mat3x3f X;
X << eval_x[face[0]], eval_x[face[1]], eval_x[face[2]];
Mat3x2f F = utility::compute_deformation_grad(X, data.inv_rest2x2[i]);
Svd3x2 svd = utility::svd3x2_shifted(F);
```

类似地在弹性嵌入（`energy/energy.cu` 的 `embed_face_force_hessian` / `embed_tet_force_hessian`）与塑性更新中反复出现。

**inv_rest 的意义**：
- 它是 rest 形状的“参考逆度量”。
- 预计算于场景构建阶段（Rust 侧 `builder.rs` 等，通过 rest 顶点位置算 dx_rest 然后求逆，存入 GPU buffer）。
- 改变 inv_rest 等价于改变该单元的 rest 参考形状（塑性流动正是通过缓慢更新 inv_rest 实现的，见 plasticity/）。
- 面积/体积加权通常在 Prop 中独立存储，F 本身不直接含缩放信息。

## SVD 与 shifted 变体

获得 F 后，项目大量使用其奇异值 σ（或 S = σ - 1）作为各向同性超弹性与应变限制的天然坐标。

**标准 SVD（壳）**（`utility/utility.cu:72`）：

```cpp
__device__ Svd3x2 svd3x2(const Mat3x2f &F) {
    Eigen::SelfAdjointEigenSolver<Mat2x2f> eigensolver;
    eigensolver.computeDirect(F.transpose() * F);
    Vec2f sigma = eigensolver.eigenvalues();
    ... sqrt + U = F * V 归一化 ...
    return {U, sigma, V.transpose()};
}
```

**shifted 变体**（用于应变限制与某些能量，`utility/utility.cu:60`）：

```cpp
__device__ Svd3x2 svd3x2_shifted(const Mat3x2f &F) {
    Mat2x2f A = F.transpose() * F - Mat2x2f::Identity();
    ... 对 A 做 eigen ...
    return {U, singular_vals_minus_one(F), V.transpose()};
}
```

`singular_vals_minus_one` 直接返回 σ - 1（用于 strainlimit >0 的判断与 barrier）。

**体 SVD 带反射修正**（`svd3x3_rv`，用于 inflate 等需要正确符号的场合）：
- 先做标准 svd3x3。
- 根据 det(U) 与 det(Vt) 在最小奇异值方向乘以 -1 修正 L 矩阵，保证旋转/反射一致性。

**预计算加速**（`main/main.cu` 与 `utility::compute_svd`）：
- 每步开始时对所有壳面批量计算当前 SVD（`Svd3x2` 数组），供 max_sigma 日志、应变限制等快速使用，避免重复 eigen。

## 壳 vs 体 vs 杆的 F 使用差异

| 维度 | F 尺寸 | SVD 例程          | 主要能量路径                  | 弯曲/其他          | inv_rest 来源     |
|------|--------|-------------------|-------------------------------|--------------------|-------------------|
| 壳   | 3×2    | svd3x2 / shifted  | eigenanalysis (DiffTable2) + BaraffWitkin 直路 | hinge (4 顶点)     | inv_rest2x2       |
| 体   | 3×3    | svd3x3_rv         | eigenanalysis (DiffTable3)    | 无（纯体积）       | inv_rest3x3       |
| 杆   | 无     | 无                | Hook（边长）+ strand（3 点角度）| 仅 2-edge 顶点触发 | initial_length    |

杆件完全绕过 F 与 SVD 路径，保持轻量且避免 1D 退化奇点。

## convert：从 F 空间回到顶点空间

本征分析得到的是 **对 F 矩阵分量的力与 Hessian**（`dedF` 3×2 或 3×3，`d2ed2F` 6×6 或 9×9）。必须通过链式法则映射回顶点位移自由度。

`utility` 提供专用 `convert_force` / `convert_hessian`（利用 inv_rest 做线性变换）：

```cpp
// 声明于 utility.hpp:53
__device__ Mat3x3f convert_force(const Mat3x2f &dedF, const Mat2x2f &inv_rest2x2);
__device__ Mat9x9f convert_hessian(const Mat6x6f &d2ed2f, const Mat2x2f &inv_rest2x2);
// 体版本类似（3x4 / 12x12）
```

在弹性与应变限制的 embed 末尾都会调用：
```cpp
dedx = utility::convert_force(dedF, data.inv_rest2x2[i]);
d2edx2 = utility::convert_hessian(d2edF2, data.inv_rest2x2[i]);
utility::atomic_embed_force<3>(face, stiffness * dedx, force);
utility::atomic_embed_hessian<3>(face, stiffness * d2edx2, fixed_hess_out);
```

这保证了所有能量项最终都以**顶点 3 维力与 3×3 块 Hessian** 的形式进入全局系统。

## 数值稳定性要点（项目内强调）

- 退化三角形/四面体（面积或体积接近 0）会导致 inv_rest 病态或 F 计算数值爆炸；构建阶段应保证质量网格。
- SVD 使用 `fmax(0.0f, ...)` 保护负特征值（浮点误差导致）。
- 杆弯曲的 `gradient_theta` 有 `kSinSqEps = 1e-12` 保护（避免 e0 // e1 时 cross 归一化产生 NaN，进而破坏 PCG 单调性）。
- 塑性更新时会回写 inv_rest，需保证只修改“拉伸/压缩”部分而保留旋转（通过 SVD 重建 F_new 再求新 inv_rest）。
