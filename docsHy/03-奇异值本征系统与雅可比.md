# 03 奇异值本征系统与雅可比（项目核心技术）

这是本项目最具特色的理论与工程贡献：**对任意各向同性超弹性势能 Ψ(σ)**（仅需其对奇异值的一阶与二阶导数），在**闭式**且**数值稳定**的条件下，计算出对变形梯度 F 矩阵分量的力雅可比，并进行**正定投影**（eigen-filtered），以保证 Newton 法可靠下降。

**强烈推荐先阅读**：[`articles/eigensys.md`](../articles/eigensys.md) —— 作者提供了完整的故事背景、推导动机、最终公式、SymPy 验证代码，以及与 Smith et al. 2019 / Poya et al. 2023 的关系。本篇文档则聚焦**项目实际代码实现**的映射（`eigenanalysis/` + `utility/` 调用点），并给出精确的 C++/CUDA 片段。

**Hindsight（2025.08.09）**：eigensys.md 开头已注明，核心洞见在 Poya et al. (2023) “Variational schemes and mixed finite elements for large strain isotropic elasticity in principal stretches...” 中已先行发展。读者引用时应优先参考原工作。本项目贡献仍在于对**壳 3×2 F** 的自然扩展、实现细节与实用工程集成。

## 问题背景（简要）

隐式模拟需要力 **f = ∂Ψ/∂x** 与力雅可比 **H = ∂²Ψ/∂x²**（x 为顶点位置）。对线性单元，F 是 x 的线性函数，因此可先在 F 空间求导，再链式映射回 x。

对于各向同性材料，Ψ 通常可写为奇异值 σ 的函数：Ψ(σ₁,σ₂,σ₃)（体）或 Ψ(σ₁,σ₂)（壳）。直接符号微分 9×9（或 6×6）H 极难；数值方法太慢；不变式方法（Smith 2019 经典工作）对某些能量（如 Ogden）表达困难，且存在 σ_i=σ_j 奇点。

**项目目标**（eigensys.md 总结）：
- 只需 ∂Ψ/∂σ 与 ∂²Ψ/∂σ²（或 invariants 的对应量）。
- 闭式、快速、简单。
- 自动处理正定投影（max(λ,0)）。
- 同时支持 3×3（体）与 3×2（壳，非方阵）。

## 最终结果（力与滤波雅可比）

### 力（一阶）
```math
\frac{\partial \Psi}{\partial f_i} = \sum_k \frac{\partial \Psi}{\partial \sigma_k} \left( u_k \cdot (S_i v_k) \right)
```
其中 S_i 是只在 f_i 对应位置为 1 的模板矩阵，u_k / v_k 来自 F 的 SVD（U Σ V^T）。

代码实现（`eigenanalysis/eigenanalysis.cu:18` for 2D，77 for 3D）使用等价的矩阵形式：
```cpp
// 2D 示例
for (int i=0; i<3; ++i) for (int j=0; j<2; ++j) {
    Mat3x2f df = ...; df(i,j)=1;
    Vec2f dadf = (Ut * df * V).diagonal();
    result(i,j) = table.deda.dot(dadf);
}
```

### 滤波雅可比（二阶，正定投影）
```math
\frac{\partial^2 \Psi}{\partial f_i \partial f_j} = \sum_{k=1}^{N} \max(\lambda_k, 0) \, q_i^{(k)} q_j^{(k)}
```
N=9（体）或 6（壳）。q 是 Q_k 矩阵在 (i,j) 位置的标量，Q_k 是“模态矩阵”（twist / flip / scaling）。

**代码入口**（`eigenanalysis.hpp:14`）：
```cpp
__device__ Mat3x2f compute_force(const DiffTable2 &table, const Svd3x2 &svd);
__device__ Mat6x6f compute_hessian(const DiffTable2 &table, const Svd3x2 &svd, float eps);
__device__ Mat3x3f compute_force(const DiffTable3 &table, const Svd3x3 &svd);
__device__ Mat9x9f compute_hessian(const DiffTable3 &table, const Svd3x3 &svd, float eps);
```

## 2D（壳）实现细节（compute_hessian 2×2 版）

`eigenanalysis.cu:33-75`：

1. 对 `table.d2ed2a`（2×2）做特征分解，得到 scaling 模式的 eigvalues / eigenvectors。
2. 构造 6 个 Q 模态（使用 expand_U 把 3×2 U 补成 3×3）：
   - Q[0..1]：twist / flip 类（固定 ±1/√2 结构）
   - Q[2..3]：法向/切向相关
   - Q[4..5]：scaling（eigvec 对角填充）
3. 计算 6 个 λ（已做 max(0,·)）：
   ```cpp
   lambda[0] = fmax(0, (deda0 + deda1)/(a0+a1) );           // 和模式
   lambda[1] = fmax(0, fabs(denom)>eps ? (deda0-deda1)/denom
                    : 0.5*(d00+d11) - 0.5*(d01+d10) );       // 差模式 + d² 近似
   lambda[2] = fmax(0, deda0 / a0);
   lambda[3] = fmax(0, deda1 / a1);
   lambda[4..5] = fmax(0, eigvalues);
   ```
4. 仅 λ>0 的模态贡献：`U * Q[i] * Vt` 向量化后外积 × λ[i] 累加。

**expand_U**（11 行）：
```cpp
Vec3f cross = U.col(0).cross(U.col(1));
result << U.col(0), U.col(1), cross;
```

## 3D（体）实现细节（compute_hessian 3×3 版）

`eigenanalysis.cu:92-150` 结构完全对称，只是规模 9：

- 9 个 Q：Q[0..2] twist、Q[3..5] flip、Q[6..8] scaling（eigvec 填充）。
- 9 个 λ：3 个“和”模式（ab/ac/bc）、3 个“差”模式（带 eps 保护 + d² 近似）、3 个 scaling eig。
- 最终：`svd.U * Q[i] * svd.Vt`（体直接用 U，不需 expand）。

**注意**：体 SVD 使用 `svd3x3_rv`（带反射修正），保证 U/Vt 行列式符号一致。

## ε（eiganalysis_eps）的作用与近似

当 σ_i ≈ σ_j 时，(deda_i - deda_j)/(σ_i - σ_j) 出现 0/0。

**项目采用的 Valanis-Landel 安全近似**（要求 Ψ 对 σ 排序不变，即各向同性）：
```math
\frac{1}{\sigma_i - \sigma_j} (\partial_i - \partial_j) \approx \frac12 (\partial_i^2 + \partial_j^2) - \partial_i\partial_j
```

代码中用 `fabs(denom) > eps ? ... : 0.5*(dii+djj)-0.5*(dij+dji)` 实现（2D lambda[1]、3D lambda[3,4,5]）。

`eps` 来自 `param.eiganalysis_eps`，默认很小但非零，用于浮点保护。所有各向同性能量都满足假设。

## 使用 Cauchy-Green 不变量的等价路径（eigensys.md 进阶）

若能量写成 I1,I2,I3（或 Smith 2019 的 invariants），可完全避免 σ 空间奇点：
- 通过链式法则把 deda / d2ed2a 用 dΨ/dI + dI/dσ 表达。
- H_3x3 也可只用 d²Ψ/dI² 与 dI/dσ 构造。
- 项目提供了 SymPy 代码证明可精确重推导 Smith et al. 的系统（eigensys.md 末尾）。
- 实际 C++ 代码中，ARAP/StVK 仍优选直接 σ 路径（更通用）；SNHk 本身就是 invariants 风格的实现。

## 壳 3×2 vs 体 3×3 的关键差异（代码与理论）

- **U 维度**：壳需 `expand_U` 补第三列（法向）；体直接用 3×3 U。
- **Q 构造数量**：壳 6 个，体 9 个（多一个 twist/flip/scaling）。
- **λ 公式**：壳只有 2 个 σ，少一个“和/差”对；体有 3 个 σ，6 个 twist/flip + 3 scaling。
- **convert**：壳用 3×2→3×3 力 + 6×6→9×9 hess；体 3×3→3×4 力 + 9×9→12×12 hess。
- 理论价值（eigensys.md）：壳扩展是本文相对 Poya 工作的实用增量。

## 与文献的关系（eigensys.md 总结）

- 可重推导 Smith et al. 2019（TOG）“Analytic Eigensystems for Isotropic Distortion Energies”的 Q1-6 + 部分 scaling。
- 数学上接近 Zhu 2021，但消除了部分奇点并提供更显式解。
- 与 Stomakhin 2012（invertible elasticity） invariants 处理相容。
- 推荐引用顺序：优先 Poya 2023 原工作 + Smith 2019；本项目实现与壳扩展可作为工程参考。

项目还提供了完整 Apache 2.0 的 C++/Rust/CUDA 实现 + Python 数值验证（`eigsys/` 目录）。

## 完整调用链路示例（壳面弹性）

1. `F = compute_deformation_grad(X, inv_rest2x2)`
2. `svd = svd3x2(F)`（或 shifted）
3. `table = XXX::make_diff_table2(svd.S, mu, lambda)` → 得到 deda / d2ed2a
4. `dedF = eigenanalysis::compute_force(table, svd)`
5. `d2edF2 = eigenanalysis::compute_hessian(table, svd, eps)`
6. `dedx = convert_force(dedF, inv_rest)`；`d2edx2 = convert_hessian(...)`
7. `atomic_embed_force<3>(face, mass*dedx, force)` + hess

（完全相同的路径也用于应变限制，只是 DiffTable 来自 `barrier::compute_strainlimiting_diff_table`。）

## 数值稳健性要点（代码内注释与实践）

- 所有 λ 都包 `fmax(0.0f, ...)` 实现 PSD 投影。
- 差模式用 eps + d² 近似。
- SVD 内部 `fmax(0.0f, eigenvalue)` 防负根。
- 壳 U 归一化 + expand 后的正交性由 cross 保证。
- 最终外积只在 λ[i]>0 时累加，稀疏高效。
