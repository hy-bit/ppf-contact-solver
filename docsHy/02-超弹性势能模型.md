# 02 超弹性势能模型

本篇系统整理项目中实现的各向同性超弹性势能模型。所有模型最终都作用于**奇异值坐标**（或直接边长/角度），并通过 `make_diff_table` 返回一阶导 `deda` 与二阶导 `d2ed2a`（DiffTable），供后续 eigenanalysis 产生 PSD 滤波的力雅可比。

**核心设计原则**（项目实现一贯）：
- 壳与体大量复用 SVD + DiffTable + eigenanalysis 路径。
- BaraffWitkin 是壳的特殊直通路径（不走 eigen）。
- 杆件完全独立（Hook + strand 角度）。
- 体积项主要通过 `detsqr`（或 SNHk 内部 I3 项）实现 det(F) ≈ 1 的惩罚。
- 弯曲能使用 Gauss-Newton 风格（g g^T）以在 rest 位保持曲率（完整 Hessian 在 rest 会坍缩）。

## 1. ARAP（As-Rigid-As-Possible）

**壳与体通用**（`energy/model/arap.hpp`）：

```cpp
// 2D (壳)
__device__ float energy(const Vec2f &a, float mu, float lmd) {
    float a0 = a[0] - 1.0f; float a1 = a[1] - 1.0f;
    return 0.5f * mu * (a0 * a0 + a1 * a1) + detsqr::energy(a, lmd);
}

// 3D 同理（三个分量）
```

**DiffTable**（make_diff_table2/3）：
- `deda = mu * (a - Ones) + detsqr_deda`
- `d2ed2a = mu * Identity + detsqr_d2`

**物理含义**：最小化奇异值到 1 的距离（即尽量保持刚性旋转+均匀缩放）。体积由 detsqr 单独控制。

## 2. StVK（St. Venant-Kirchhoff，带 detsqr 体积）

**壳/体**（`energy/model/stvk.hpp:17`）：

```cpp
__device__ float energy(const Vec2f &a, float mu, float lmd) {
    float a0 = a[0] - 1.0f; float a1 = a[1] - 1.0f;
    return mu * (sqr(a0) * sqr(a0) + sqr(a1) * sqr(a1)) / 4.0f +
           detsqr::energy(a, lmd);
}
// 3D 版本扩展三个分量
```

梯度（mu 部分）：`Vec(a0^3, a1^3)`（3D 三个）

Hessian（mu 部分）：diag(3 a0², 3 a1²)

**完整 DiffTable** = mu 部分 + detsqr 叠加。

**对应连续形式**（约）：Ψ_stretch ≈ (μ/4) Σ (σ_i - 1)^4 + (λ/2)(J-1)^2（J = ∏ σ_i）。

## 3. SNHk（Stable Neo-Hookean 变体）

**不使用 detsqr**，直接在 σ 上写 I2/I3 形式（`energy/model/snhk.hpp:14`）：

```cpp
// 3D
__device__ float energy(const Vec3f &S, float mu, float lmd) {
    float a = S[0], b = S[1], c = S[2];
    float I2 = a*a + b*b + c*c;
    float I3 = a*b*c;
    return 0.5f * mu * (I2 - 3.0f) - mu * (I3 - 1.0f) +
           0.5f * lmd * (I3 - 1.0f) * (I3 - 1.0f);
}
```

**DiffTable 直接展开**（make_diff_table3，无中间 detsqr 调用）：
- deda[0] = lmd * b*c*(I3-1) + mu*(a - b*c)  等
- d2ed2a 含 lmd * (b b c c) + mu 等对角 + 交叉项 lmd*I3*c - mu*c 等

2D 版本类似（I3 = a*b）。

**特点**：对 inversion 相对鲁棒（I3 项），在项目中被推荐用于某些高应变场景。体积稳定性内建于 I3 惩罚。

## 4. BaraffWitkin（壳专用，直接作用于 F）

**不走 SVD + DiffTable + eigen** 路径（`energy/model/baraffwitkin.hpp` + energy.cu:220 分支）。

- Stretch（u/v 方向）：
  ```cpp
  float i5u = F.col(0).squaredNorm();
  float i5v = F.col(1).squaredNorm();
  return 0.5f * mu * (sqr(sqrtf(i5u)-1) + sqr(sqrtf(i5v)-1));
  ```
- Shear：
  ```cpp
  float i6 = F.col(0).dot(F.col(1));
  return 0.5f * lmd * sqr(i6);
  ```

梯度/ hessian 直接对 Mat3x2f F 写出（stretch_gradient / shear_gradient + 复杂的解析 hessian，使用正交基 q1/q2... 构造局部 3×3 块 + max(0, λ) 投影）。

**在 embed 中**：`dedF = de0 + de1; d2edF2 = ...` 后直接 convert（无 eigen filter 步骤）。

**适用**：传统布料模拟中常用的各向异性拉伸+剪切分离模型。项目中仅壳支持。

## 5. 体积项：detsqr

**独立模块**（`energy/model/detsqr.hpp`），被 ARAP 与 StVK 显式叠加：

```cpp
// 2D
__device__ float energy(const Vec2f &a, float lmd) {
    float a0 = a[0]-1, a1 = a[1]-1;
    return lmd * 0.5f * sqr(a0 * a1 - 1.0f);
}
// 3D 三个分量乘积

// DiffTable 显式：
J = a0*a1 (2D) 或 a0*a1*a2 (3D)
deda[0] = lmd * a1 * (J-1)   // 2D 示例
d2ed2a(0,0) = lmd * sqr(a1)
d2ed2a(0,1) = lmd * (2*J - 1)
```

**作用**：惩罚 J = det(F) 偏离 1，实现近似不可压缩体积响应。λ 通常远大于 μ（体积模量大）。

**SNHk 不调用它**，而是把等效体积行为写进自己的 I3 公式。

## 6. 杆拉伸：Hook 模型

**完全不使用 F/SVD**（`energy/model/hook.hpp:14`）：

```cpp
__device__ float energy(const Vec3f &x0, const Vec3f &x1, float l0) {
    Vec3f t = x1 - x0;
    float r = t.norm() / l0 - 1.0f;
    return 0.5f * r * r;
}
```

`make_diff_table` 返回 3×2 梯度（对两个顶点）与 6×6 hessian：
- 使用方向 n 与长度偏差 r。
- 采用带死区的 Gauss-Newton 风格（c0/c1 系数：`fmax(0,1-r)/l0` 等），保证 PSD。
- weight 由 `stiffness` 参数缩放。

## 7. 弯曲能（壳 hinge + 杆 strand）

统一位于 `energy/model/dihedral_angle.hpp`。

**壳 hinge（四顶点）**：
- 能量：`0.5 * (theta - rest_angle)^2`
- theta = signed angle between two face normals（`face_dihedral_angle` 用 acos + 叉积符号判断）。
- 力与 hess：`(theta-rest) * grad` + `g g^T`（Gauss-Newton）。
- grad 解析表达式基于 e0,e1,n1,n2（`face_dihedral_angle_grad`）。

**杆 strand（三顶点）**：
- 类似角度定义（`strand_energy` 用 acos(e0·e1 / norms)）。
- `strand_compute_force_hessian` 同上模式。
- **重要数值保护**（117 行注释）：
  ```cpp
  constexpr float kSinSqEps = 1e-12f;
  if (cross_sqnm <= kSinSqEps * e0_sqnm * e1_sqnm) {
      return Mat3x2f::Zero();   // 避免 NaN 破坏 PCG
  }
  ```
- 刚度：`0.5*(bend0 + bend1) * mass`（或面积相关因子）。

**嵌入位置**：
- 壳弯曲：`embed_hinge_force_hessian`（仅 type &1 ==0 的 hinge）
- 杆弯曲：`embed_rod_bend_force_hessian`（仅 surface vert 恰好 2 条边 + 0 面时触发）

|---------------|--------------|-------------------------------------------|------------|--------------|------|
| ARAP          | 壳+体        | (μ/2) Σ(a_i-1)² + detsqr                  | detsqr     | 是           | 刚性优先 |

## 其他相关能量（简要）

- **Inflate / Pressure**（壳）：`inflate.hpp`，基于 det 项 + 秩 5 PSD 投影 hess（SVD 分析细节见文件内长注释）。
- **Air damper + wind**：每顶点/面阻尼 + 风力（`air_damper.hpp`、`get_wind_weight`）。

- 以上均在 Newton 装配阶段与弹性并列累加到 force/hess（见 07 管线篇）。

## 塑性与 rest 形状演化（与弹性正交）

塑性（`plasticity/plasticity.cu`）在每步**之后**运行：
- 壳/体：当前 F → SVD → 对 |σ_i - 1| 超过阈值的分量做死区 creep（alpha = 1 - exp(-plasticity * dt)）→ 重建新 F → 更新 inv_rest（保持旋转部分）。
- 弯曲（hinge/杆）：直接 creep 更新 rest_angle / rest_bend_angle。
- 结果：弹性势能定义不变，但“参考形状”缓慢松弛，实现永久变形。

这与应变限制（每 Newton 迭代内、强约束）形成互补。
